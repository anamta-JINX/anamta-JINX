## about

I build **AI systems and software products** — mostly LLM/RAG systems, backend architecture, full-stack applications, and experiments that somehow become real projects.

I care about what happens **under the hood**: how the model works, how the data moves, how the system scales, and whether the final thing is actually pleasant to use.

`currently` independent LLMs · RAG · intelligent backends · voice systems  
`off-screen` chess · basketball · Rubik's cube in ~20s · aggressively curious rabbit holes

> **build it. break it. understand it. ship it better.**
